### XP Reward System

| Level | Per Question | Pass Bonus | Perfect Bonus | 5Q Perfect Total |
|-------|-------------|------------|---------------|------------------|
| Simple | 3 XP | +5 XP | +5 XP | **25 XP** |
| Standard | 5 XP | +10 XP | +15 XP | **50 XP** |
| Deep | 8 XP | +20 XP | +30 XP | **90 XP** |

### Gamification Rules by Level

```javascript
simple: {
  streakThresholds: [2, 4],
  multipliers: [1, 1.25, 1.5],
  speedBonusEnabled: false,
  hintsAllowed: 3,
  celebrationStyle: 'playful'
}

standard: {
  streakThresholds: [3, 5],
  multipliers: [1, 1.5, 2],
  speedBonusEnabled: true,
  speedThreshold: 15s,
  hintsAllowed: 1,
  celebrationStyle: 'balanced'
}

deep: {
  streakThresholds: [3, 5],
  multipliers: [1, 1.5, 2],
  speedBonusEnabled: true,
  speedThreshold: 10s,
  hintsAllowed: 0,
  celebrationStyle: 'intense'
}
```

| Deep | mcq (analytical), find_error, sequence (6-8 items), apply_concept |
